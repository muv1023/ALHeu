# BAN 517 — Algorithms & Heuristics Decision Lab

Streamlit companion for the Module 5 Algorithms and Heuristics assignment.

Students do the calculations outside the app using the course methods, then enter their results for automated checking.

## Student workflow
1. Enter name and student ID.
2. Download the routing, bin-packing, and shortest-path datasets.
3. Complete Nearest Neighbor and 2-Opt.
4. Complete Sweep/VRP.
5. Complete all four bin-packing heuristics.
6. Complete Dijkstra's Algorithm.
7. Enter the final comparison result.
8. Download the verified PDF and submit it with the Excel workbook.

## Deployment
- Main file: `app.py`
- Python dependencies: `requirements.txt`
- Data: `data/`
- Instructor answers must be stored in Streamlit Secrets and never committed to GitHub.
